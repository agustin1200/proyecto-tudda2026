# Instrucciones para puesta en funcionamiento

1.Clonar el repositorio.
2.Copiar el archivo de configuracion config.example.js => config.js
3.Editar el archivo config.js para colocar los datos nesesarios: puerto y conexion a la BDD.
4.Instalar dependencia: >npm install.
5.Iniciar la aplicacion: >npm run dev.
